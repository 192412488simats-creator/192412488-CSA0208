## Question Details

### Q1 – Searching a Library Catalogue
Implements linear search and binary search to find book accession numbers. Counts comparisons and compares search efficiency.

### Q2 – Sorting the Examination Hall Seating Register
Implements bubble sort, selection sort and insertion sort. Compares their performance using different input arrangements.

### Q3 – Merging Two Merit Lists
Merges two sorted merit lists into one descending-order list without sorting again. Handles equal scores and empty lists.

### Q4 – Two-Dimensional Arrays: District Rainfall Records
Uses a two-dimensional array to calculate district rainfall totals, state monthly average, maximum rainfall and deficient districts.

### Q5 – Processing Text Without the Library
Implements word counting, uppercase conversion, string reversal and palindrome checking using character arrays and loops.

### Q6 – A Directory of Names: Sorting and Searching Strings
Stores resident names, sorts them alphabetically, searches using binary search and identifies duplicate names.

### Q7 – Design an Election Counting Program from First Principles
Counts valid and invalid votes, calculates candidate totals, displays results in descending order and identifies the winner or a tie.
