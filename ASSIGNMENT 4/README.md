# ADVANCED DATA STRUCTURES AND DESIGN ENGINEERING

## Assignment – C Programming

**Total Marks:** 50  
**Number of Tasks:** 6

## Description

This repository contains C programs developed for the Advanced Data Structures and Design Engineering assignment. It covers structure design, nested structures, unions, memory layout, pointers, storage classes and practical data management applications.

## Tasks Included

### Task 1 – Data Design Review
- Diagnose problems in a patient register data design.
- Implement structures and nested structures.
- Add and sort patient records using structure pointers.

### Task 2 – From Requirement to Nested Structures
- Design structures for courier parcel tracking.
- Implement nested structures for addresses and dates.
- Sort parcels by weight and display parcels by receiver city.

### Task 3 – Unions and Memory Layout
- Compare structures and unions.
- Implement tagged unions for weather station packets.
- Demonstrate memory allocation using `sizeof()`.

### Task 4 – Structure Forensics
- Identify errors in structure handling.
- Demonstrate structure pointers and address comparison.
- Implement an interest calculation program using pointers.

### Task 5 – Storage Classes
- Demonstrate automatic, static, global and register storage classes.
- Implement token counters.
- Compare their scope, lifetime and behaviour.

### Task 6 – Design Challenge
- Design a college canteen inventory and billing system.
- Implement structures and tagged unions.
- Record sales, validate stock, check expiry dates and generate revenue summaries.

## Technologies Used
- Programming Language: C
- Compiler: GCC


## Conclusion

This assignment provides practical experience in designing and implementing C programs using structures, nested structures, unions, pointers and storage classes. It helps develop problem-solving skills and understand efficient data organization and memory management.
