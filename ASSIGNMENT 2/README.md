## Question Details

### Q1 – Precedence, Associativity and the Discount Bug
Analyses operator precedence, associativity, integer division and undefined behaviour. Implements a corrected pharmacy billing calculation using intermediate variables.

### Q2 – When Does Short-Circuit Evaluation Matter?
Demonstrates short-circuit evaluation using logical AND (&&), logical OR (||), and bitwise operators. Measures function calls and compares condition ordering.

### Q3 – Engineer a Device-Status Register with Bitwise Operators
Uses bitwise operators to switch devices ON/OFF, toggle device states, test bits, display binary values and count active devices.

### Q4 – else-if Ladder or switch?
Implements a grade classifier using both else-if and switch statements. Tests boundary values and explains switch fall-through and lookup tables.

### Q5 – Count the Work Done by a Loop
Implements prime-number checking using different loops. Compares the number of divisions performed by basic and optimised methods.

### Q6 – Loops That Must Terminate: Loan Repayment Schedule
Develops a loan repayment schedule using loops. Calculates monthly interest, repayment, total interest and repayment duration with a safety limit.

### Q7 – Diagnose, Redesign and Validate
Identifies a limitation in an existing program, redesigns it for improved performance, and compares the original and improved solutions using test results.
